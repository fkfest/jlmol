About JLmol

JLmol is a powerful desktop application designed for molecular visualization and analysis, built on the robust foundation of Electron and the renowned JSmol molecular viewer. Our mission is to provide researchers, educators, and students with a native desktop experience that combines the flexibility of web technologies with the performance and integration capabilities of desktop applications.

Our Vision

We believe that molecular visualization should be accessible, powerful, and intuitive. JLmol bridges the gap between complex molecular data and clear, interactive visualizations that help advance scientific understanding and education.

Key Technologies

JLmol is built on proven, open-source technologies:

  • JSmol: The JavaScript port of the famous Jmol molecular viewer
  • Electron: Cross-platform desktop application framework
  • JSME: JavaScript Molecular Editor for structure drawing
  • ModelKit: Advanced 3D molecular editing capabilities

Development Philosophy

Our development is guided by principles of openness, accessibility, and scientific rigor. We maintain compatibility with established molecular file formats while embracing modern web technologies to create a seamless user experience.

Community and Support

JLmol is developed as an open-source project with the molecular science community in mind. We welcome contributions, feedback, and collaboration from researchers, developers, and educators worldwide.
