ElemCo.jl Integration

JLmol offers deep integration with ElemCo.jl, a modern Julia-based quantum chemistry package. This enables users to go from structure visualization to high-level computation and back, all within a single interface. The integration is designed for both beginners and advanced users, with support for local, WSL, and remote execution.

Input Generation:

  • Automatically generate ElemCo.jl input files from any loaded structure.
  • Select quantum chemistry methods: HF, MP2, CCSD, CCSD(T), and more.
  • Choose basis sets and toggle density fitting for supported methods.
  • Inputs are formatted for direct use with ElemCo.jl, minimizing manual editing.

Calculation Runner:

  • Run calculations locally, in WSL (Windows Subsystem for Linux), or remotely via SSH.
  • Customizable Julia command and environment for advanced workflows.
  • Integrated log viewer for monitoring calculation progress and troubleshooting errors.
  • Supports batch jobs and large molecule calculations (subject to system resources).

User Preferences & Technical Details:

  • Configure Julia executable path, default methods, and basis sets in the settings panel.
  • Preferences are saved between sessions for a persistent workflow.
  • Calculation output can be visualized directly (orbitals, energies, etc.).
  • Handles errors gracefully and provides detailed feedback for failed jobs.

Best Practices & Troubleshooting:

  • Set up your Julia environment and ElemCo.jl installation before running calculations.
  • For remote jobs, ensure SSH keys and permissions are configured correctly.
  • Check calculation logs for errors or warnings if results are unexpected.
  • Use the integrated runner for rapid prototyping and the command line for large-scale jobs.
