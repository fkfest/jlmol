PubChem Database Integration

JLmol integrates a robust PubChem search and retrieval system, allowing you to fetch molecular structures directly from the world's largest open chemical database. The search interface is designed for both speed and flexibility, supporting multiple query types and advanced error handling.

Supported Search Types:

  • Compound ID (CID): Enter a numeric PubChem CID for precise retrieval (e.g., 1983 for caffeine).
  • Chemical Name: Use IUPAC, common, or trade names (e.g., aspirin, acetaminophen).
  • Formula: Input molecular formulas (e.g., C2H5OH for ethanol).
  • SMILES: Paste SMILES strings for exact structure matches (e.g., CC(=O)O for acetic acid).

Interface Features:

  • Unified Search Field: Enter any supported query type in a single field. The app auto-detects the type or lets you force a specific mode.
  • Type Selector: Override auto-detection to force CID, Name, or SMILES search.
  • Quick Load: Press Enter to instantly fetch and display the molecule.
  • Error Handling: Clear feedback for network issues, invalid queries, or not found results.
  • Network Robustness: Handles PubChem downtime or slow responses gracefully.

Technical Details:

  • Uses PubChem PUG REST API for all queries.
  • Automatically parses and converts downloaded structures to supported formats for visualization and editing.
  • Supports batch queries and large molecule retrieval (subject to PubChem limits).

Best Practices & Troubleshooting:

  • Use CID for the most reliable and unambiguous results.
  • If a search fails, try alternate names or SMILES for the same compound.
  • Downloaded structures can be immediately edited or exported in other formats.
  • For very large molecules, consider using a simplified display style for performance.
