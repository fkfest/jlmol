Multi-Format Support

JLmol supports a wide range of chemical file formats for both import and export, making it easy to integrate with other tools and databases. Each format has its own strengths and is suited for different workflows in chemistry and computational research.

Supported Formats & Details:

  • XYZ: Simple text format for atomic coordinates. Fast to load and edit, but lacks bond information.
  • PDB: Protein Data Bank format, supports biomolecules, chains, and secondary structure. Ideal for proteins and nucleic acids.
  • MOL: Common for small molecules, includes atom types and bond orders. Widely used in cheminformatics.
  • CIF: Crystallographic Information File, for crystal structures, symmetry, and unit cell data. Used in solid-state chemistry.
  • MOLDEN: Quantum chemistry output, includes orbitals and vibrational modes. Required for advanced analysis in JLmol.

How to Use:

  • Load files via the file menu or drag-and-drop. JLmol auto-detects the format and parses accordingly.
  • Edit and save structures in your preferred format for use in other software.
  • Export the current structure to Molden format with a customizable file name for use in downstream quantum chemistry tools.
  • Switch between formats to ensure compatibility with your workflow or collaborators.

Technical Details:

  • Automatic format detection based on file extension and content.
  • Preserves as much information as possible when converting between formats, but some data (e.g., PDB chain info) may be lost in simpler formats.
  • Handles large files efficiently, but performance may vary with very large biomolecules or crystals.

Best Practices & Troubleshooting:

  • Use XYZ for quick edits and small molecules, PDB for proteins, and MOLDEN for quantum chemistry results.
  • If a file fails to load, check for formatting errors or try converting to a simpler format.
  • For best results, use standard-compliant files and avoid exotic or proprietary extensions.
